## 已知问题与限制

- 没有真人试玩数据：真人用时、难度曲线、操作灵敏度和辅助强度都还是设计估计。
- 指针锁定在普通浏览器窗口中的表现未验证（测试环境不授予指针锁定；退回的“按住左键拖动观察”已验证）。
- 程序化音效未经人耳检查；Firefox / Safari 未测试；不支持触屏设备。
- 首次加载：程序约 2 MB（gzip，其中物理引擎含 WebAssembly 约 1.7 MB），另外进入地图时加载模型与贴图约 17–21 MB（驾驶舱 6.3 MB、直升机外观 0.5 MB、树木 3 MB、该地图建筑 3.3–5.4 MB、地形照片材质 3.8–6.1 MB；低画质不加载地形照片材质）；之后由浏览器缓存。
- 建筑模型按每栋的宽 / 长 / 高缩放，屋顶坡度会随之略有变化；码头、帐篷、集装箱、机库、油罐等通用小道具仍是程序几何体（叠加了照片细节贴图）。
- 集成显卡上帧率较低（树木和建筑模型更新前，在核显上测得低画质约 22 帧）。双显卡笔记本请在 Windows「设置 → 系统 → 屏幕 → 显示卡」里把浏览器设为“高性能”，游戏首次启动时也会按显卡自动选画质并在主菜单提示。
- 远处峭壁在近距离仍有细小的颗粒纹理（岩石细节噪声），属于风格取舍。

## 可以继续改进的方向

- 收集真人试玩反馈后调整：辅助强度、按键灵敏度、各地图任务难度与补给位置。
- 手柄/摇杆支持；更多视角（外部自由视角、回放）。
- 旋翼下洗效果（扬尘、水面涟漪、草地倒伏）。
- 通用小道具（码头、集装箱、机库等）也换成 Blender 模型；模型贴图的法线 / 粗糙度图可以降到 512 以减小下载量。
- 低配置设备的进一步优化（更激进的远景简化）。

## 发布状态（2026-11-03）

- **代码**：已推送到私有仓库 https://github.com/tenshojin/rotor-trails ，分支 `main`（画面升级于 2026-11-03 下午推送）。
- **持续集成**：推送后 GitHub Actions “CI / Pages” 自动运行，`build` 任务通过（Ubuntu + Node 24：`npm ci`、类型检查、81 个测试全部通过、生产构建），用时约 50 秒。
- **私有试玩页**（claude.ai Artifact，只有所有者能打开）已更新为画面升级版：`npm run build` 后用 `node tools/artifact-page.mjs <输出 html>` 生成页面与附属文件清单（模型以 base64 文本发布）。
- **网页上线：尚未上线。** `deploy` 任务按设计跳过，GitHub Pages 没有开启，原因：
  1. 私有仓库使用 GitHub Pages 需要付费方案（GitHub Pro / Team / Enterprise）；免费账号需要把仓库改为公开。
  2. 开启 Pages 会让游戏网站对所有人公开可访问，属于仓库所有者的发布决定，没有得到授权前不擅自开启、也不改变仓库可见性。
- 需要上线时：在 Settings → Pages 把 Source 设为 “GitHub Actions”，再新建仓库变量 `DEPLOY_PAGES=true`（或手动运行一次工作流）；部署完成后访问 Pages 网址验证。在本地也可以随时用 `npm run build` + `npm run preview` 运行生产版本。
