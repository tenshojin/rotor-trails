## 已知问题与限制

- 没有真人试玩数据：真人用时、难度曲线、操作灵敏度和辅助强度都还是设计估计。
- 指针锁定在普通浏览器窗口中的表现未验证（测试环境不授予指针锁定；退回的“按住左键拖动观察”已验证）。
- 程序化音效和背景音乐未经人耳检查（离线渲染量过响度、频谱、节奏，见 test-report）；Firefox / Safari 未测试；手机和平板只用触屏模拟测过，没有上过真机。
- 首次加载：程序约 2 MB（gzip，其中物理引擎含 WebAssembly 约 1.7 MB），另外进入地图时加载模型与贴图约 17–21 MB（驾驶舱 6.3 MB、直升机外观 0.5 MB、树木 3 MB、该地图建筑 3.3–5.4 MB、地形照片材质 3.8–6.1 MB；低画质不加载地形照片材质）；之后由浏览器缓存。
- 建筑模型按每栋的宽 / 长 / 高缩放，屋顶坡度会随之略有变化；码头、帐篷、集装箱、机库、油罐等通用小道具仍是程序几何体（叠加了照片细节贴图）。
- 集成显卡上帧率较低（树木和建筑模型更新前，在核显上测得低画质约 22 帧）。双显卡笔记本请在 Windows「设置 → 系统 → 屏幕 → 显示卡」里把浏览器设为“高性能”，游戏首次启动时也会按显卡自动选画质并在主菜单提示。
- 远处峭壁在近距离仍有细小的颗粒纹理（岩石细节噪声），属于风格取舍。
