# Rotor Trails

[简体中文](README.md) | [English](README.en.md) | **日本語**

ブラウザで動く、一人称視点のヘリコプターシミュレーターです。ダウンロードもインストールも不要。ページを開けばすぐに飛べます。日本の湾に浮かぶ島々、アメリカ南西部の峡谷、アマゾンの熱帯雨林、ノルウェーのフィヨルド、ヒマラヤの雪山、そして実測データから作ったグランドキャニオン。

**プレイはこちら：https://tenshojin.github.io/rotor-trails/**

パソコンではキーボードとマウス、またはゲームパッド（Xbox / PS 配置）で操縦します。スマートフォンとタブレットでは端末を横向きにして、画面上の 2 本のスティックで飛びます（フルシムはパソコン専用です）。デスクトップ版の Chrome か Edge で、ハードウェアアクセラレーションを有効にして遊ぶことをおすすめします。進行状況はお使いのブラウザに保存されます。日本語・英語・簡体字中国語に対応していて、ブラウザの言語に合わせて表示されます。メインメニュー右上でいつでも切り替えられます。初めての方は、まず「フライトスクール」からどうぞ。

## 遊び方

- **ミッション**：5 つのマップで、輸送、物資の投下、巡回、精密着陸に挑みます。途中でルートを選べる場面があり、サブ目標もあります。時間制限はなく、飛行の質で評価されます。
- **フリーフライト**：ミッションも時間制限もなく、ぶつけても失敗になりません。時間帯と天気を選んだら、空中からスタート。飛行中でも時間帯や天気を変えたり、名所へジャンプしたりできます。J を押すと名所を自動で巡り、V でシネマカメラに切り替えれば、あとは景色を眺めるだけ。ある場所に着くと、その地名と一言が画面に浮かびます。訪れた場所は記録され、ポーズメニューでまだ行っていない場所とその方角を確認できます。クリックすれば、そこまで自動で飛んでいきます。
- **フライトスクール**：2 つのコースがあります。基本飛行は 7 レッスン。周りを見回すところから始めて、一度にひとつの動作だけを学びます。フルシムは 8 レッスン。コールドスタートから空中でのエンジン停止まで学びます。墜落してもそのレッスンの最初に戻るだけで、失敗にはなりません。
- **フォトモード**：ポーズメニューから入ります。世界が止まり、カメラは自由に置けて、焦点距離、露出、傾き、背景のボケを調整できます。フィルム、ウォーム、クール、モノクロなどのスタイルを選べ、ヘリコプターを隠して風景だけを撮ることもできます。F で UI のない画像を保存します。
- **リプレイ**：ポーズメニュー、リザルト画面、失敗画面から見られます。シネマカメラが直前の 4 分間を再生します。スロー再生、カメラの切り替え、シークができ、どのコマからでもフォトモードに入れます。
- **フライトログ**：メインメニューにあります。飛行時間、安全な着陸の回数、最もやさしい着陸、訪れた場所の数を確認でき、13 個のメダルを集められます。
- **クレジット**：最後のマップを終えたあと、または「このゲームについて」から。夕暮れの瀬戸湾を自動で巡る飛行の上をクレジットが流れ、終わったらそのまま飛び続けられます。
- **フルシム**：飛行アシストは一切なし。135 個のボタンとスイッチはすべて本物で、マウスで操作できます。

## 特徴

- **重さを感じる飛行**：揚力は機体の傾きと一緒に傾き、加速にも減速にも旋回にも時間と距離が必要です。標高が高いほど空気が薄くなり、パワーの余裕が減っていきます。
- **アシストは好みで選べる**：初心者、標準、チャレンジの 3 段階。アシストは機体を安定させるだけで、慣性や風を打ち消すことはありません。ホバリングアシスト（H）は最初はオフで、初心者アシストでは、うまく止まれないときに使い方を教えてくれます。すべて自分でやりたいなら、フルシムを選んでください。
- **生きている世界**：ハゲワシが崖沿いを旋回し、カモメが港の上を舞い、オウムがつがいで熱帯雨林を横切ります。近づくと道を空けてくれます。フェリーや漁船が白い航跡を引いて海を行き、アマゾン川を客船が上り下りし、訓練場の上空では軽飛行機が離着陸の練習をしています。岩壁の近くを飛ぶと、ローターの音が壁から跳ね返ってきます。
- **本物の風**：定常風、突風、峡谷の風の通り道、上昇気流と下降気流が機体を押し流します。吹き流し、旗、祈祷旗、木々、雨の筋が風向きを教えてくれます。吹き流しは風の強さもわかります。1 節ふくらむごとに約 3 ノット、まっすぐ水平なら 15 ノット（約 8 m/s）以上です。目標地点のオレンジ色の発煙も風に流され、風が強いほど大きく傾きます。風が強いと海には白波が立ち、水面が波立つと遠くの島の映り込みは空の色に溶けていきます。鏡のようになるのは、穏やかな日だけです。
- **ローターが起こす風**：低く飛ぶと、木や低木や草が波のように外側へなびき、水しぶきや土ぼこりが舞い上がります。普段の風でも、大きな木はゆっくり、小さな木や低木は速く揺れ、梢は幹より大きくしなり、枝葉はそれぞれに震えます。
- **天気と時間帯**：晴れ、雨、豪雨、濃霧、低い雲、小雪、晴れのち豪雨。昼、早朝、夕暮れ、夜。雨は風に流されて斜めに降り、豪雨では稲妻が地面に落ち、数秒遅れて雷鳴が届きます。早朝は谷に朝霧がかかり、雨上がりには屋根も地面も濡れ、雪の日は地面や屋根や梢が少しずつ白くなっていきます。夜は星空と天の川、月明かり、ときおり流れる流星。ノルウェーのフィヨルドの空にはオーロラがかかり、機内には計器のバックライトが灯ります。
- **壁紙にしたくなる風景**：層ごとに風化した岩壁、山や木々を映す水面、雲の切れ間や林を抜ける光の筋。視線を動かすと、目がゆっくりと明るさに慣れていきます。
- **見て触れるコックピット**：アナログ計器に加えて、エンジン、地図、姿勢のディスプレイがリアルタイムで動きます。振り向けば座席もドアも後部キャビンも見えます。
- **サウンド**：ローター、エンジン、風、警報はすべてリアルタイムに合成され、回転数や気流に合わせて変化します。メインメニューとフリーフライトでは自動生成の BGM が流れ、設定でオフにできます。
- **耐久と着陸判定**：損傷すると性能が徐々に落ちますが、操縦はいつでも利きます。何かにぶつかると土ぼこりや水しぶき、破片が飛び、損傷した機体は煙を引き、風防にはひびが入ります。着陸は降下率、横流れ、姿勢、位置の 4 項目で判定されます。
- **見えるものにはすべて当たる**：湾を行くフェリーや漁船、道路を走る車、飛行場の上を回る小型機、さらに街灯、照明柱、旗竿、吹き流しの支柱、駐車中の車、鳥居の横木まで、触れれば損傷します。ブレードが細い柱をかすめても同じです。
- **届けた物資**：降ろした荷物はヘリパッドの端に一箱ずつ積まれていきます。
- **詰まない設計**：直前のチェックポイントや手前の安全なチェックポイントから再開でき、「セーフリカバリー」で安定したホバリング状態に戻ることもできます。
- **道中の補給**：パワーブースト、シールド、修理キット。
- **画質**：低・中・高・最高の 4 段階。初回起動時にグラフィックカードに合わせて自動で選ばれます。画質が高いほど遠くまで見え、最高画質では木が 6 km 先まで描かれ、地形や建物のディテール、影もより遠くまで届きます。レイトレーシングのスイッチもあり、日陰の岩壁が向かいの壁の暖かい色を受け、機体の腹には地面からの反射光が届きます。
- **セーブデータの持ち運び**：進行状況はブラウザに保存され、ファイルに書き出して別のパソコンやブラウザで読み込めます（設定 → アシストと表示）。

### グランドキャニオン

このマップはアルゴリズムで生成したものではありません。すべての峰、すべての地層が現実と同じ場所にあります。標高は米国地質調査所の測量データ、地表は 2023 年の航空写真で、サウスリムの木は航空写真から一本ずつ判別しました。

超大型マップで、41 × 41 km の全域を飛べます。サウスリムのマーザー・ポイントからコロラド川まで降り、ノースリムのロッジ、ケープ・ロイヤル、ハーミッツ・レストまで飛んでいけます。中央の 10 km が最も精細で、低く飛ぶと遊歩道や車線、駐車場の車まで見分けられます（30 cm の航空写真を飛んだ先から読み込みます。画質「低」では使いません）。その外側は、地面すれすれを飛ぶと少しぼやけます。初めてこのマップに入るときに約 90 MB をダウンロードします。

## 操作

ゲームパッドのボタン配置は、ゲーム内の「操作方法」にあります。ゲームパッドを手に取ると、画面のヒントやチュートリアルがゲームパッドのボタン表示に変わり、飛行中に接続が切れると自動でポーズします。メニューでは右スティックで長いページをスクロール。フォトモードでは十字キー左右で焦点距離や露出などの項目を選び、上下で調整します。リプレイでは A で一時停止、LB / RB で 5 秒戻る / 進む。フルシムをゲームパッドで遊ぶときは画面中央に照準が出ます。右スティックで視線をスイッチに合わせ、A で前へ、X で手前へ、長押しでノブを回し、左スティックの押し込みでトリムを取ります。

スマートフォンとタブレット：画面左の小さなパネルに対地速度、対地高度、耐久が表示されます。ホバリングとクルーズはオンの間ボタンが光り、パワーブーストを持っていないときはブーストボタンが暗くなります。ミッションの分岐では、ルートカードをタップしておすすめルートを選べます。iPhone の Safari はウェブページを全画面にできないので、共有 →「ホーム画面に追加」を使ってください。ホーム画面から開くと、横向きの全画面で起動します。

飛行中にブラウザの「戻る」（スマートフォンの戻るボタン、マウスのサイドボタン）を押すとポーズになり、ページを離れることはありません。パソコンでは、設定 → グラフィックに全画面ボタンがあります。

| キー | 操作 |
| --- | --- |
| W / S | 前傾して加速 / 後傾して減速 |
| A / D | 左旋回 / 右旋回 |
| スペース | 上昇 |
| Shift | 降下 |
| Q / E | 左へ / 右へ平行移動 |
| H | ホバリングアシスト：徐々に減速して位置を保つ |
| C | パワーブースト |
| マウス | 周囲を見回す（機体の向きは変わりません） |
| Z / V | 視点リセット / 視点切り替え（フリーフライトのみ。ミッションと訓練はコックピット固定） |
| N / M | ナビの目標を切り替え / コックピットの地図の範囲 |
| U | HUD：自動、すべて、非表示 |
| F | スクリーンショット：HUD なしでこのコマを保存。ポーズ中も撮れます。アングルを決めたいときはポーズメニューからフォトモードへ |
| J | オートクルーズ（フリーフライト）：名所を自動で巡ります。操縦キーに触れると操縦が戻ります |
| Esc または P | ポーズ |

すべてのキーは「設定 → 操作」で変更できます。

## フルシム

ミッションのブリーフィングの「飛行アシスト」で「フルシム」を選ぶか、フリーフライトの「飛び方」で選びます。初めての方は、先に「フライトスクール → フルシム」を受けることをおすすめします（約 20 分）。

- **コールドスタート**：機体は電源が落ちた状態です。左上のチェックリストに沿って一つずつ操作するか、「自動で完了」をクリックします。
- **マウスがあなたの目と指**：画面の端へ動かすと視線が動き、端に近いほど速く回ります。コントロールに合わせるだけなら名前と数値が出るだけで、クリックして初めて操作になります。左クリックで操作、右クリックで一段戻す、ホイールでノブを回します。
- **飛行アシストなし**：ローター回転数は自分で監視します。エンジンが止まればオートローテーションで降りるしかなく、降下が速すぎるとボルテックス・リングに入り、速度超過では後退側ブレードが失速し、トルク超過はメインギアボックスを傷めます。

| キー | 操作 |
| --- | --- |
| W / S | サイクリック前後 |
| A / D | 低速ではペダル、速度が出るとおもにバンク |
| Q / E | サイクリック左右 |
| スペース / Shift | コレクティブを引く / 下げる（離した位置にとどまります） |
| C | パワーブースト |
| T | トリム：今のスティック位置を、手を離したときに戻る位置にする |
| H | 安定増強（SAS）のオン / オフ |

**機体がいつも右に回りたがるのは、バグではなく本物の物理です。** 上から見ると、メインローターは反時計回りに回っています。エンジンがローターを左へねじると、ローターは胴体を右へねじり返します。これが反トルクです。SAS がオンなら代わりに抑えてくれますが、オフにしたら自分で A を軽く押して左ペダルを踏む必要があります。ホバリングでは約 10%。ペダルは踏んだ位置にとどまります。

Windows の「固定キー機能」は、Shift を 5 回続けて押すとポップアップが出ます。Shift で降下することが多い場合は、Windows の設定 → アクセシビリティ → キーボードで、そのショートカットをオフにできます。

## クレジットとライセンス

グランドキャニオンの標高データは USGS 3DEP、画像は USDA NAIP（USGS The National Map 経由）のもので、いずれも米国政府のパブリックドメインデータです。マテリアルは [Poly Haven](https://polyhaven.com)（CC0）を使用しています。サードパーティのオープンソースライブラリのライセンスは [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md) をご覧ください。

このプロジェクト自身のコードには、まだオープンソースライセンスを指定していません（既定ではすべての権利を留保します）。開発に関する説明は [docs/development.md](docs/development.md) にあります（中国語）。
